# 推币机可上架运营检查清单

## 结论
当前仓库是**可玩的Demo版本**，不是可直接上架运营版本。

## 还缺哪些运营级模块
- 登录与云存档（游客/平台账号）
- 支付与订单校验（服务端签名）
- 广告SDK（激励视频/插屏/Banner）
- 反作弊（分数回放校验、速率检测、服务端风控）
- 数据埋点与A/B实验
- 活动与热更配置（远端下发）
- 用户协议/隐私合规（未成年、GDPR/CCPA）
- 崩溃监控与告警（Sentry/自建）
- 客服入口与封禁策略

## 当前代码已补的运营基础
- 本地持久化存档 `PersistenceService.ts`
- 运营参数与日常任务定义 `LiveOpsConfig.ts`
- 单局结算回写生涯数据 `GameManager.ts`

## 上架建议里程碑
1. M1（1-2周）：接入埋点、崩溃、基础云存档
2. M2（2-4周）：广告 + IAP + 服务端订单校验
3. M3（4-6周）：活动系统 + A/B + 反作弊
4. M4（6-8周）：多渠道适配与提审
